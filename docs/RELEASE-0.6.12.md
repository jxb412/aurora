# 云桥 AI · yunqiao.me 0.6.12

[下载本版](https://github.com/jxb412/yunqiao.me/releases/tag/v0.6.12) · [安装说明](../INSTALLATION.md) · [使用指南](../USER-GUIDE.md)

本版完善 ChatGPT / Codex 的 API 网关配置：保留客户端原生指令、图片输入和模型能力，同时让上下文与自动压缩设置保持一致。

- **模型能力保留。** 模型资料完整且适合当前历史时，按模型使用各自的上下文、推理档位和图片能力。资料不足时继续使用客户端原有能力，不生成空指令或擅自关闭图片输入。
- **上下文与 90% 压缩。** 正常使用所选模型的上下文窗口，默认达到 90% 时触发自动压缩。例如设置 272000，对应阈值 244800。旧会话无法安全匹配模型目录时，保留所选模型的窗口和阈值，避免续聊误用过大的默认窗口。
- **先完成配置。** 客户端运行中、历史暂不可读或预览后运行状态变化，都不会仅因此要求退出再重新应用。可以先保存，重启客户端后加载新配置；历史能处理时再单独备份和修复。
- **自定义目录可恢复。** 为 API 接入使用独立模型目录，原自定义目录和内容保持可恢复。重新配置、切换接入方式和恢复原配置时，保留用户后来修改的内容，并明确提示真正的配置冲突。

## 升级后怎么使用

1. 退出云桥，安装或完整解压新版；已有本机数据保留。
2. 打开 **客户端接入**，选择供应商和模型，确认模型的上下文大小。
3. 点击 **预览配置 → 保存配置**。看到 **配置已保存，重启客户端后生效** 后即可继续；历史提示稍后处理不代表配置失败。
4. 保存工作后 **重新启动客户端**，发送文字或图片验证。模型和上游接口需要支持所发送的内容；使用本地网关或官方账号共存时保持云桥运行。

配置文件自身确实无法写入，或被其他程序修改时，会保留现状并提示原因。新版不会将这些真实写入失败显示成成功。

## 下载与安装

Windows 提供安装版、免安装版及完整 ZIP；macOS 提供 Apple M 系列和 Intel 的 DMG / ZIP。Windows ZIP 请完整解压后运行 `YunQiaoAI.exe`；Mac 将 `YunQiaoAI.app` 放入“应用程序”。

macOS 包尚未签名与公证。确认来自项目发布页后，若首次打开提示“已损坏”，在终端运行：

```bash
xattr -cr "/Applications/YunQiaoAI.app"
```

应用内更新优先使用 GitHub，官网作为备用来源。
